# 🚏 Smart Bus Stop System

**A modern, interactive bus stop system for real-time tracking and efficient public transportation.**

## 🌟 Features
✅ Live bus tracking 📍  
✅ Estimated arrival times ⏳  
✅ Interactive passenger UI 🖥️  
✅ Admin dashboard for management 🛠️  

## 🛠️ Tech Stack
- **Frontend:** Vue.js / React  
- **Backend:** Node.js (Express)  
- **Database:** MySQL (bus_booking.sql)  
- **Other:** Vite, ESLint  

## 🚀 Getting Started

### 1️⃣ Clone the Repository
```bash
https://github.com/HasiniRajapaksha/SmartBusStop
cd SmartBusStop
```

### 2️⃣ Install Dependencies
```bash
npm install
```

### 3️⃣ Set Up the Database
- Import `bus_booking.sql` into MySQL.

### 4️⃣ Start the Server
```bash
node server.js
```

### 5️⃣ Run the Frontend
```bash
npm run dev
```
